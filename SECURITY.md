# Reporting security issues

Do not include real genomes, credentials or sensitive input in a public issue.
For parser crashes without sensitive material, provide a small synthetic
reproducer, version, platform and command through GitHub issues.

For a vulnerability whose details should remain private, use GitHub's private
vulnerability reporting option when available, or ask the maintainer for a private
reporting channel without posting exploit details. No response-time guarantee is
currently offered. Supported release/platform status is documented in the README.
